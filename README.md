# MV Forros - Forro PVC e Drywall

Landing page profissional para a empresa **MV Forros**, especializada em instalação e venda de forros em PVC e divisórias em Drywall na região de Itaquaquecetuba e arredores.

## 🏢 Sobre a Empresa

**MV Forros** oferece soluções profissionais em:
- **Forro PVC**: Forros de alta qualidade, duráveis e fáceis de limpar, ideais para cozinhas, banheiros e áreas molhadas
- **Divisórias Drywall**: Divisórias para ambientes internos com acabamento liso e profissional
- **Venda de Materiais**: Fornecimento de materiais de qualidade para seus projetos

## 🌐 Tecnologias Utilizadas

- **React 19**: Framework JavaScript para construção da interface
- **Tailwind CSS 4**: Framework de CSS para estilização
- **shadcn/ui**: Componentes UI acessíveis e reutilizáveis
- **Vite**: Build tool moderno e rápido
- **TypeScript**: Tipagem estática para JavaScript

## 📁 Estrutura do Projeto

```
client/
  ├── public/          # Arquivos estáticos (favicon, robots.txt)
  ├── src/
  │   ├── pages/       # Páginas da aplicação
  │   ├── components/  # Componentes reutilizáveis
```

## 🚀 Como Executar

### Desenvolvimento

```bash
# Instalar dependências
pnpm install

# Iniciar servidor de desenvolvimento
pnpm dev
```

O site estará disponível em `http://localhost:3000`

### Build para Produção

```bash
# Compilar para produção
pnpm build

# Visualizar build de produção
pnpm preview
```
